# AMASS HANDICRAFTS

A handcrafted home décor storefront concept featuring a premium dark-and-gold visual style and a product-card layout.

## Current page

The site is a static HTML storefront with:

- AMASS HANDICRAFTS branding
- Collection navigation labels
- A responsive product-card grid
- Product imagery stored alongside the HTML file
- WhatsApp order links on product cards

## Project files

- `index.html` — storefront markup and embedded CSS
- `IMG_0487.png` — logo image used in the header
- `IMG_2788.png` — image used in the banner and product cards

## Preview locally

1. Download or clone this repository.
2. Keep the image files in the same folder as `index.html`.
3. Open `index.html` in a browser.

## Before publishing

Review product names, photos, prices, discounts, review counts, and WhatsApp contact details to ensure they are current and accurate. The values displayed in the sample page should not be treated as verified live inventory or pricing.
